# 📌 Overview

**ResolveAI** is an AI-powered Multi-Agent Debt Resolution Platform designed to help banks, NBFCs, and financial institutions recover overdue payments through **ethical, personalized, and intelligent borrower interactions**.

Unlike traditional debt collection systems that rely on repetitive manual calls, ResolveAI coordinates multiple specialized AI agents to understand borrower situations, negotiate customized repayment plans, maintain conversation memory, and escalate only when necessary.

# 🎯 Core AI Agents

### 🧠 Master Orchestrator Agent
Coordinates the complete workflow.

### 👤 Borrower Intelligence Agent
Creates borrower profiles using financial and behavioral data.

### 📊 Risk Prediction Agent
Predicts repayment probability and prioritizes cases.

### 💬 Chat Negotiation Agent
Collects borrower information and begins negotiation.

### 📞 Voice Negotiation Agent
Continues conversations naturally without repeating questions.

### 🤝 Resolution Agent
Generates personalized repayment plans.

### 🛡 Compliance Guard Agent
Ensures ethical and regulatory-compliant communication.

### 🧠 Shared Memory Agent
Maintains context across every interaction.
